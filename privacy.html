آخر تحديث: 27 نوفمبر 2026

تنبيه: MAVORA حالياً نموذج تجريبي. لا تدخل أسماء أو أرقام هواتف أو عناوين أو أي بيانات شخصية تخص زبائنك. هذا البيان يصف سلوك النموذج الحالي فقط، وليس سياسة الخصوصية النهائية لخدمة SaaS.

1. البيانات في النسخة التجريبية

تُحفظ بيانات المنتجات والطلبات التجريبية التي تدخلها في التخزين المحلي لمتصفح الجهاز باستخدام localStorage. لا توفر هذه النسخة قاعدة بيانات سحابية أو حسابات مستخدمين أو مزامنة بين الأجهزة.

2. مسؤولية المستخدم

استخدم بيانات اختبار غير حقيقية فقط. لا تدخل بيانات العملاء أو معلومات الدفع أو كلمات المرور أو أي معلومات سرية.

3. ملفات الارتباط والتتبع

لا تتضمن النسخة الحالية أدوات تحليلات أو إعلانات مدمجة من طرف MAVORA. قد يخضع تصفح GitHub Pages والبنية المستضيفة لسياسات مزود الاستضافة.

4. خدمات خارجية

يتم استضافة الملفات الثابتة عبر GitHub Pages. لم يتم تفعيل مزود قاعدة بيانات أو ذكاء اصطناعي أو WhatsApp أو بوابة دفع في هذه النسخة.

5. قبل الإطلاق التجاري

يجب نشر سياسة نهائية تحدد هوية المسؤول عن المعالجة ووسائل التواصل، وفئات البيانات والأغراض والأساس القانوني ومدد الاحتفاظ والمستلمين ومواقع الاستضافة وحقوق الأشخاص وآليات ممارستها، وإتمام إجراءات CNDP المطلوبة قبل تشغيل المعالجات ذات الصلة. يجب مراجعة أي نقل بيانات خارج المغرب ومتطلبات القانون 09-08 مع مختص.

6. التواصل

لم يتم بعد تعيين بريد دعم رسمي منشور. لن نضع عنواناً غير مؤكد في هذه الصفحة. يجب إضافة بيانات المسؤول ووسائل التواصل قبل الإطلاق العام.
