# MAVORA — MVP 0.1

واجهة عربية أولية لإدارة المنتجات والمخزون والطلبات.

## الموجود حالياً
- لوحة تحكم متجاوبة بالعربية.
- إضافة وتعديل وحذف المنتجات.
- بحث في المنتجات وحساب قيمة المخزون.
- تنبيه بصري للمخزون المنخفض.
- إنشاء طلبات تجريبية وتحديث الكمية.
- مساعد كتالوج محلي يعرض بيانات المنتجات المسجلة فقط.
- حفظ محلي في متصفح الجهاز عبر localStorage.
- أساس PWA عبر manifest وservice worker.

## حدود النسخة
هذه نسخة MVP تجريبية وليست SaaS جاهزاً للإنتاج. لا توجد قاعدة بيانات سحابية أو مزامنة أو حسابات أو عزل بيانات المتاجر أو ذكاء اصطناعي حقيقي أو تكامل WhatsApp أو دفع إلكتروني أو نسخ احتياطي. لا تدخل بيانات عملاء حقيقية. يلزم Backend آمن واختبارات قبل الاستخدام التجاري.

## التشغيل
انشر الملفات على استضافة صفحات ثابتة تدعم HTTPS، أو افتح index.html للتجربة المحلية.
